MooLog PWA package

Upload ALL files and folders together to an HTTPS web host.
Required:
- index.html
- manifest.webmanifest
- service-worker.js
- icons/icon-192.png
- icons/icon-512.png

After hosting, open the HTTPS address in Chrome on Android and choose:
More (⋮) > Install and create shortcut > Install.

Important: browser localStorage belongs to the web address it was created under.
Data stored in an older downloaded/file:// copy will not automatically move to a newly hosted address.
